# MNIST Handwritten Digit Recognition

This is my first Machine Learning project for recognizing handwritten digits. The neural network is built entirely from scratch using NumPy, without relying on high-level machine learning frameworks like TensorFlow or PyTorch.
By manually implementing all the mathematical functions and core algorithms, I gained a much deeper understanding of the fundamental mechanics behind how neural networks operate.

## Installation & Setup
**Clone this repository:**
```
git clone https://github.com/hnx07/Handwritten-digit-recognition.git
cd Handwritten-digit-recognition
```

**Install required library:**
```
pip install -r requirements.txt
```

**Launch digit recognition:**
```
python app.py
```
